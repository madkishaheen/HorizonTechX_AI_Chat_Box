# 🤖 AI Chat Box -- Java

## 📌 Project Overview

AI Chat Box is a simple **Java-based rule-based chatbot** developed as a
programming project.

The chatbot can understand different types of user questions and provide
predefined responses. It also supports basic Java and OOP questions,
date and time, and simple calculations.

------------------------------------------------------------------------

## ✨ Features

The chatbot can:

-   👋 Respond to greetings
-   💬 Handle basic conversation
-   ☕ Answer basic Java questions
-   🧩 Explain Object-Oriented Programming (OOP)
-   📚 Explain classes and objects
-   🔐 Explain Encapsulation
-   🧬 Explain Inheritance
-   🔄 Explain Polymorphism
-   🎯 Explain Abstraction
-   📦 Explain Arrays
-   🔤 Explain Strings
-   📝 Explain Variables
-   📅 Display the current date
-   ⏰ Display the current time
-   🧮 Perform basic calculations
-   ❓ Provide a help menu

# ▶️ How to Run the Project

## 1. Install Java

Make sure Java is installed on your computer.

Open **Command Prompt** or **PowerShell** and type:

``` bash
java -version
```

Then check the Java compiler:

``` bash
javac -version
```

If both commands show a Java version, Java is installed correctly.

------------------------------------------------------------------------

## 2. Download the Project

Clone the GitHub repository using:

``` bash
git clone https://github.com/madkishaheen/HorizonTechX_AI_Chat_Box.git
```

Move into the project folder:

``` bash
cd HorizonTechX_AI_Chat_Box
```

------------------------------------------------------------------------

## 3. Compile the Java Files

Run:

``` bash
javac Chatbot.java Main.java
```

If there are no errors, the files have been compiled successfully.

------------------------------------------------------------------------

## 4. Run the Chatbot

Run:

``` bash
java Main
```

The chatbot will start in the terminal.
